สำหรับ บริษัท NONYUBAN จำกัด (NONYUBAN Co., Ltd.)

Executive Summary

เว็บแอปพลิเคชันนี้ถูกสร้างขึ้นเพื่อนำเสนอโครงสร้างผู้บริหารของ บริษัท NONYUBAN จำกัด ในรูปแบบ Agentic 3D Parallax Interactive Gallery ประกอบด้วยตำแหน่งสำคัญ ได้แก่ 1. ประธานบริษัท, 2. ฝ่ายการเงิน, 3. ฝ่ายปฏิบัติการ และ 4. ฝ่ายการตลาด โดยใช้ภาพบุคลากรจริงและออกแบบด้วย Visual & Interaction Level ล้ำสมัยเพื่อสร้างความน่าเชื่อถือให้กับองค์กร

1. แนวความคิดการออกแบบ (Design & UX Concept)

  • Agentic 3D Parallax Depth: เมื่อเมาส์เคลื่อนที่ผ่าน Card จะเกิดแรงเอียงสมจริง (rotateX, rotateY) ขณะที่ภาพพื้นหลังฉายแบบ Parallax ซ้อนมิติ สร้าง visual dynamic ที่ดึงดูดสายตา
  • Dark Luxury Palette: ใช้เฉดสีมืดลุ่มลึกผสานกับสีทองเกรเดียนต์และนีออนอินดิโก เพื่อสื่อถึงความทันสมัยและความมั่นคงขององค์กร
  • Responsiveness & Smooth Interaction: รองรับการปัดและแสดงผลอย่างเรียบร้อยสมบูรณ์บนทุกหน้าจอทั้ง มือถือ แท็บเล็ต และเดสก์ท็อป

2. สมาชิกทีมงานทั้ง 4 ฝ่ายหลัก

01. ประธานบริษัท (CEO)

คุณสุจิตราภรณ์ หาแสง

วางทิศทางและวิสัยทัศน์ความมั่นคงของ บริษัท NONYUBAN จำกัด

02. ฝ่ายการเงิน (CFO)

คุณเกรียงศักดิ์ ปานสวย

กำกับดูแลผลประโยชน์ การลงทุน และความเสถียรภาพทางการเงิน

03. ฝ่ายปฏิบัติการ (COO)

คุณรดา นกเสวก

ควบคุมระบบการบริหารงาน internal flow ให้เกิดประสิทธิภาพสูงสุด

04. ฝ่ายการตลาด (CMO)

คุณลัดดาวัลย์ ราหุละ

วางแผนกลยุทธ์การตลาด การสื่อสารแบรนด์ และขยายฐานลูกค้า

3. การนำขึ้นแสดงผลบน GitHub Pages

# 1. สร้าง Git Repository และ Commit ไฟล์

git init

git add index.html images/

git commit -m "Deploy NONYUBAN Co., Ltd. Team Gallery"

# 2. Push ขึ้น GitHub

git branch -M main

git remote add origin https://github.com/your-username/nonyuban-gallery.git

git push -u origin main

# 3. เปิดใช้งาน GitHub Pages

ไปที่ Repository Settings > Pages > Source เลือก 'main' branch แล้วกด Save
